# 🧪 devsec-lab

Laboratório pessoal de estudos e experimentos em:
- Cybersecurity (Red Team / Pentest ético)
- Python
- Redes, scanners e enumeração
- Automação e lógica
- Inteligência Artificial (aprendizado inicial)

Este repositório não é um único projeto “grande”.
Ele é o meu espaço de prática: cada pasta aqui dentro é um mini-projeto, um teste ou um exercício que eu estou desenvolvendo enquanto estudo informática e segurança ofensiva.

---



## 🎯 Objetivo

- Aprender segurança ofensiva de forma ética.
- Automatizar raciocínio: fazer ferramentas que ajudem a identificar problemas.
- Pensar como atacante para defender melhor.
- Evoluir em Python escrevendo utilitários reais, não só teoria.

> “Every system has a vulnerability — the key is to understand it, not exploit it.”

---

## ⚠ Nota ética

Tudo aqui tem foco educacional, estudo pessoal e desenvolvimento profissional.
Nenhum script deve ser usado contra sistemas/serviços sem autorização explícita do dono.
Hacking sem permissão = crime.
Hacking com permissão = segurança.
